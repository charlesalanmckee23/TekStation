# TekStation iOS — Step 1

This is the **Capacitor-ready iOS package** for the current TekStation web application. It is intentionally additive: the existing web application remains the source of truth, while this project provides the native iOS shell needed for App Store distribution.

## Preserved from the current TekStation build

- Planner and progression calculations
- Specimen implant screenshot scanner
- Characters / builds
- Creature database and connected planning
- Crafting, bosses and Tekgrams
- Official servers, Small Tribes, favorites, history and matchmaking
- Maps and connected map intelligence
- Survivor Ops / Field Intel
- Data Vault, encrypted account sync and recovery
- Resend-backed transactional welcome email flow

## Native-safe web routing

When running inside Capacitor, `/api/servers`, `/api/vault`, and `/api/account` are routed to `https://tekstation.app`. In the normal browser build, the existing relative API routes are unchanged.

Shared build links always use `https://tekstation.app`, so an iPhone user never shares a `capacitor://localhost` address.

The existing browser service worker is kept browser-only; the native app does not attempt to register it.

## Cloud / Windows workflow

This package does **not** contain a generated Xcode `ios/` project yet. That project must be generated by the Capacitor CLI on a macOS/Xcode environment. You can do that on a cloud macOS CI service without owning a Mac.

From the project root on the cloud Mac:

```bash
npm install
npx cap add ios
npx cap sync ios
```

Then open/build the generated Xcode project and configure Apple signing for TestFlight/App Store Connect.

Capacitor's current documentation is v8 and documents adding Capacitor to an existing web app and adding the iOS platform with `npx cap add ios`. The package follows that current major version. ([capacitorjs.com](https://capacitorjs.com/docs))

## Apple requirement

As of April 28, 2026, Apple requires App Store Connect uploads to be built with **Xcode 26 or later using the iOS 26 SDK or later**. The cloud macOS runner we use for the final build must therefore provide a compatible Xcode 26+ environment. ([developer.apple.com](https://developer.apple.com/news/upcoming-requirements/))

## App identity

- App name: `TekStation`
- Bundle ID: `app.tekstation.app`

The bundle ID should be registered in the Apple Developer account before the final signing/build step.

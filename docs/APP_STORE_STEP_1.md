# TekStation App Store — Step 1

Prepared the existing TekStation build for Capacitor 8 / iOS.

Next:
1. Put this project in GitHub.
2. Run `npm install` on a cloud macOS runner.
3. Run `npx cap add ios`.
4. Run `npx cap sync ios`.
5. Configure Apple signing and App Store Connect.
6. Add/test native camera/photo, notifications and share integrations.
7. Build and upload to TestFlight.

Apple currently requires App Store Connect uploads to use Xcode 26+ with the iOS 26 SDK. See the current Apple requirements before selecting the cloud runner.

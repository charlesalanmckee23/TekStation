# TekStation server detail update

Clicking an official server now opens a detail sheet with:
- server name
- map, mode, region
- live player count / capacity
- ping when Wildcard provides it
- supported platforms
- copy-server-name action
- BattleMetrics search link

Important limitation: ARK: Survival Ascended official servers currently expose the live player count but do not expose the connected player-name list through the public server interface. The UI therefore does not invent or imply a player list. If Wildcard adds public player-list support later, the detail panel can be extended to display names.

# TekStation Visual Redesign v2

This build keeps all existing content and functionality intact. It adds a CSS-only visual system focused on ARK: Survival Ascended usability: stronger contrast, clearer information hierarchy, more durable panel surfaces, game-state colors, denser scanning, and a deliberate light theme.

The service-worker cache was bumped to `asa-v103` so the new styling is picked up after deployment.


## Theme default
TekStation defaults to dark mode for new visitors. Light mode remains available only when explicitly selected and that preference is remembered.
